### Contenido de cada unidad

**[Unidad 1 — Probabilidades](Unidad%201/resumen.md)**
Experimentos y sucesos, definiciones de probabilidad (clásica, frecuencial y axiomática), probabilidad condicional, probabilidad total, Bayes e independencia.

**[Unidad 2 — Variables aleatorias](Unidad%202/resumen.md)**
Variables discretas y continuas, función de probabilidad, densidad y distribución, esperanza, varianza, distribución conjunta, covarianza y correlación.

**[Unidad 3 — Variables aleatorias especiales](Unidad%203/resumen.md)**
Bernoulli, Binomial, Hipergeométrica, Poisson, Uniforme, Exponencial y Normal, y la relación entre Exponencial y Poisson.

## Cómo usar los ejercicios

Cada ejercicio tiene un botón **Solución** que muestra la respuesta. Dentro aparece otro botón, **Solución paso a paso**, con el desarrollo completo. Así se puede intentar resolverlo antes de mirar.
